# Учет посещаемости студентов

Учебный проект по варианту 25. Система предназначена для преподавателя, который отмечает посещение занятий, студента, который просматривает свои пропуски и диаграмму посещаемости, и администратора, который управляет пользователями и группами.

## Планируемые возможности

- Регистрация и вход с разграничением ролей.
- Ведение групп, студентов и занятий.
- Отметка присутствия и пропусков.
- Просмотр собственных пропусков и диаграммы посещаемости.

## Планируемый стек

Python, Django, PostgreSQL, Docker Compose.

## Организация работы

`main` — стабильная версия; `develop` — текущая разработка. Новые функции выполняются в ветках `feature/...` и добавляются в `develop` через Pull request после проверки кода.

## Состояние проекта

Исследовательский этап: собраны требования, пользовательские истории, приоритеты MoSCoW, план работ и реестр рисков. Инструкция по запуску будет добавлена после реализации приложения.
