# Самопроверка перед ревью

Внешние замечания и одобрение Kiromaka пока не получены. Ниже — решения по результатам собственной проверки реализации.

| Проверяемая проблема | Принятое решение | Проверка |
|---|---|---|
| Повторная отметка создает дубль | UNIQUE lesson/student; в форме update_or_create; в API PATCH | duplicate_mark, html_repeat_save |
| Студент получает чужие данные | Фильтрация по пользователю до поиска объекта | student_cannot_read_other_marks |
| Преподаватель обращается к чужой группе | Область доступа через Assignment | teacher_only_own_lessons, teacher_cannot_create_foreign_lesson |
| Студент из другой группы в журнале | Валидация пары студент/занятие | wrong_group_rejected |
| Изменение связей портит историю | Блокировка изменения группы, назначения и связанной роли | student_cannot_be_moved, assignment_cannot_change, role_cannot_break |
| Удаление незаметно стирает отметки | Подтверждение + atomic; справочники PROTECT | delete_lesson_requires_confirmation, protected_group |
| Нет отметок — деление на ноль | percentage=null, «Нет данных» | empty_statistics |
| Неподтвержденная форма меняет данные | Django CSRF и SessionAuthentication | login_csrf, session_api_csrf |

Проверено: 26 тестов на SQLite и PostgreSQL; миграции без расхождений; два контейнера healthy; успешный вход преподавателя; POST /api/lessons/ → 201 в браузере.

Ограничения этапа: нет CSV, истории аудита исправлений и интеграции с университетом; эти функции не заявляются выполненными. Устойчивость под нагрузкой и конкурентное редактирование нескольких преподавателей отдельно не измерялись. Учетные записи демо локальные.
